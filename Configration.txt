servers configuration

email server:
open the server and click the service tab
there choose email

make sure SMTP and POP3 are on
there give the domain: campus.com

and give every pc that needs email a user name and password.

in each PC:
open desktop and click the email tab
there fill the name as anything

the email address should be username@domainname(admin@campus.com)

in the server info: as both incoming and outgoing mail server put the ip address of the email server(20.0.0.2)

the username and password should be the same as the one filled in the email server.


-----------------------------------------------

ftp server:
click the ftp server and open the ftp tab
give a user and a password for the ftp server

give all the permission(write, read, delete, rename, list) to the server and add it

and on the pc go the desktop tab and open the text editor and save it(ctrl + s) ftp.txt then exit.

open command prompt and enter in the command:
dir: to see is if the file was saved properly

ftp <ip address of the server>: to access the server
the server will prompt for a username and after that a password

put ftp.txt: adding this file to the server
dir: check the if the file has been added correctly


open another pc and access the ftp using the username and password.
dir: look for the file added by the previous pc
get ftp.txt: to download it on the local pc from the server

ctrl+c: to exit ftp
dir: to check the localhost for the file that was downloaded


------------------------------------------------------

dns server:
click the dns server and open the dns tab
name: cisco.com(or any other domain name)
address: 192.168.8.4(the address of the web server)
add

what this will do is instead of going to a web browser and write the ip address(which can be tedious), only write the domain name and the website can be accessed

firewall on every server

Block Ping Requests: Rule 1 (Deny, ICMP, 0.0.0.0, 255.255.255.255) blocks all ICMP traffic (like ping or traceroute commands) from every device on the network. If you try to ping the server from any PC, you will get a "Request Timed Out" message.

Allow All Other Traffic: Rule 2 (Allow, IP, 0.0.0.0, 255.255.255.255) acts as a catch-all that allows all standard IP-based data traffic (like your HTTP Web browsing, DNS lookups, and SMTP/POP3 Emails) to pass through normally.
